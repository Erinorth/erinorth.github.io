Data Deletion

Instructions for deleting data inside the MealRecovery app.

Delete a single day log

  1. Open the MealRecovery app.
  2. Go to the Log tab.
  3. In the "Logged today" card, tap Delete today log.

This deletes only today's log.

Delete all logs

  1. Open the MealRecovery app.
  2. Go to the History tab.
  3. Scroll to Data tools.
  4. Tap Clear all logs and confirm.

This removes all stored meal timing logs and resets your streak history.

Guest mode note

Guest mode has no account data on the server. Clearing logs in the app removes local data.

ลบข้อมูล

คำแนะนำในการลบข้อมูลในแอป MealRecovery

ลบบันทึกเพียงวันเดียว

  1. เปิดแอป MealRecovery
  2. ไปที่แท็บ Log
  3. ในการ์ด "Logged today" แตะ Delete today log

การลบนี้จะลบเฉพาะบันทึกของวันนี้เท่านั้น

ลบบันทึกทั้งหมด

  1. เปิดแอป MealRecovery
  2. ไปที่แท็บ History
  3. เลื่อนไปที่ Data tools
  4. แตะ Clear all logs และยืนยัน

การลบนี้จะลบบันทึกเวลาทานอาหารทั้งหมดและรีเซ็ตประวัติ Streak ของคุณ

หมายเหตุสำหรับโหมดผู้เยี่ยมชม

โหมดผู้เยี่ยมชมไม่มีข้อมูลบัญชีบนเซิร์ฟเวอร์ การลบบันทึกในแอปจะลบข้อมูลในเครื่องเท่านั้น
